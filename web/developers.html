Как сделан проект

Технологии, архитектура и история создания — от первой идеи до приложения под Android, iPhone и ПК.

01 / Стек технологий

Из чего это собрано

Нативное приложение и веб-версия работают с одним и тем же API школьного журнала.

Kotlin 2.0 Jetpack Compose Lumo UI Compose BOM 2024.09 OkHttp Gson Coroutines Android SDK 34 Gradle 8.9 AGP 8.4 HTML / CSS / JS PHP (прокси)
02 / Платформы

Одна логика — три платформы

Android01

Нативное приложение

Kotlin + Jetpack Compose, кастомная тема Lumo. Авторизация через Ext JS cookies, автообновления через update.json, сборка в APK.

Веб02

Веб-версия

HTML, CSS и JS без сборки. Работает в браузере телефона и ПК, добавляется на домашний экран как иконка. Общается с журналом через небольшой PHP-прокси.

Простая версия03

Для кнопочных телефонов

Упрощённая страница с минимальным JS и чистым SHA-1 — работает на старых браузерах и кнопочных телефонах.

03 / API

Взаимодействие с сервером

Источник данных — АИАС АВЕРС (журнал school28-kirov.ru). Основные запросы:

POST /loginАвторизация: логин и SHA-1 пароля
POST /authПодтверждение сессии: userId и действие
GET_STUDENT_DAIRYДневник: темы уроков, домашние задания и оценки по дням
GET_STUDENT_LESSONSУроки и отметки за учебный год
GET_STUDENT_DIRECTOR_DATAИтоговые оценки по четвертям и полугодиям
GET_TIMETABLEРасписание уроков
GET_STUDENT_SUBJECTSСписок предметов ученика
GET_PERSON_STORE_DATAСправочник учителей
GET_STUDENT_CLASSКласс ученика на текущий учебный год
04 / История

От идеи до приложения

01

Старт проекта

Первая версия нативного Android-приложения для школы №28 города Кирова. Интерфейс на View-фрагментах и ViewPager2.

02

Переход на Jetpack Compose

Полная переработка интерфейса: фрагменты заменены на Compose-экраны, добавлена тема Lumo с кастомной палитрой.

03

Сайт обновлений

Лендинг на хостинге с защищённой админ-панелью загрузки и автообновлениями приложения.

04

Веб-версии

Клиент для iPhone и ПК на том же API, а также упрощённая страница для кнопочных телефонов.
