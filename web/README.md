# Веб-версия «Электронного дневника» (ЛинТех 28)

Статичная веб-версия Android-приложения для `journal.school28-kirov.ru`.
Воспроизводит экраны приложения: вход, дневник по неделям, оценки, поиск,
темы (системная/светлая/тёмная).

## Как это работает

- Браузер хранит логин/пароль в `localStorage` (как приложение — на устройстве).
- Браузер **не может** вручную ставить заголовок `Cookie`, а сессия АВЕРС
  построена на Ext JS cookies (`ys-user`, `ys-password`, `ys-userId`) с
  `jsEscape()`-кодированием.
- Поэтому все запросы идут через `proxy.php`, который обращается к журналу
  от лица сервера и подставляет нужный `Cookie`-заголовок.

## Файлы

| Файл        | Назначение                                             |
|-------------|--------------------------------------------------------|
| `index.html`| Вся разметка и логика экранов (встроенный JS)          |
| `style.css` | Тема (порт палитры приложения: светлая/тёмная)         |
| `app.js`    | Клиент API — порт `ApiClient.kt` (SHA-1, jsEscape, new Date) |
| `proxy.php` | Прокси CORS на сервер журнала                          |

## Простая версия для кнопочных телефонов

Папка `web/basic/` — упрощённая версия (один `index.html` + `proxy.php`):

- Минимальный JS, совместимый со старыми браузерами (XHR вместо `fetch`,
  чистый JS SHA-1 без `crypto.subtle`, нет вкладок — только «неделя» и «оценки»).
- Логин/пароль хранятся в cookie браузера.
- Загрузка: `basic/index.html` и `basic/proxy.php` в ту же папку
  (например `public_html/diary/basic/`). Откройте `.../diary/basic/index.html`.

## Установка на хостинг (Beget)

1. Создайте папку на хостинге, например `public_html/diary/`.
2. Загрузите все 4 файла туда (`index.html`, `style.css`, `app.js`, `proxy.php`).
3. Убедитесь, что хостинг поддерживает PHP (на Beget это по умолчанию).
4. Откройте `https://ваш-домен/diary/index.html`.

Ничего настраивать не нужно: домен журнала и путь к прокси зашиты в `app.js`
(`PROXY = 'proxy.php'`, `BASE_URL` внутри прокси).

## Проверка

- `proxy.php` принимает POST JSON `{ "e": "/act/...", "p": {...}, "cookie": "...", "get": false }`
  и возвращает `{ "ok": true, "text": "<ответ>" }` либо `{ "ok": false, "error": "..." }`.
- Endpoint допускается только в виде пути внутри журнала (защита от SSRF).
